## Cursor Cloud specific instructions

This repository is a **GitHub profile README** repo (`esmondo/esmondo`). It contains only `README.md` — there is no application code, package manifest, build system, test suite, lint config, or services.

- There are no dependencies to install and nothing to build, lint, or test. The "product" is the Markdown in `README.md`, which GitHub renders on the profile page.
- To develop, edit `README.md` and preview the rendered Markdown (GitHub-Flavored Markdown). Any Markdown previewer works; there is no repo-provided tooling.
- Many badges/images in the README are external (shields.io, github-readme-stats) and require network access to display when previewing.
